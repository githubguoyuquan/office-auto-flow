Office Auto Flow — 2026-11-18 完整交付版

只需要安装一个部分：本压缩包内的 Windows .exe 安装程序。

1. 退出旧工作台，等待自动化浏览器和服务退出。
2. 双击 .exe 覆盖安装；无需先卸载。
3. 从桌面“AIOA API 工作台”快捷方式启动。
4. 工作台固定地址：http://127.0.0.1:54418/

本安装包已包含全部累计改动：工艺单打印、PPTX 面辅料提取、供应商查询及名称映射、制作模板、网络路径选择，以及任务重置和任务准备交互优化。
无需另外安装 Python、Go、签发工具或中间更新包。
本版授权全部开放；以后收到免签 .oaf-update 文件时，可在“应用配置 → 软件更新”导入。

使用前配置
- 工艺单打印、PPTX 供应商补全：在应用配置中填写 OA 登录地址。
- 供应商名称映射表可在应用配置上传；没有映射时保留供应商编号。
- PPTX 供应商补全需要模板包含“供应商”或“供应商1/供应商2”列。
- 网络文件需要当前 Windows 账号已能访问共享目录；可先用资源管理器打开网络路径。

配置、模板、供应商映射及登录会话会保留；OA 登录过期时需重新登录。
不要再安装今天生成的旧中间版本或旧界面更新包。
.sha256 是校验文件，不需要安装。

本次修复：Edge 超时接口兼容、任务启动与配置选择交互、内置 OA 地址自动配置、供应商查询不再要求模板包含辅料编号。
本安装包已包含界面 0.3.10，请勿再导入 0.3.4 至 0.3.10 的旧更新包。
